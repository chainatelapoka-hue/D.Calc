# D. Calc (Android Calculator, Ledger & Business Suite)

## GitHub থেকে APK ফাইল ডাউনলোড করার নিয়ম (How to Download APK from GitHub)

এই প্রজেক্টটি GitHub-এ Push করার সাথে সাথেই GitHub Actions স্বয়ংক্রিয়ভাবে **`D-Calc.apk`** তৈরি করে দেবে। ডাউনলোড করার জন্য নিচের যেকোনো একটি উপায় অনুসরণ করুন:

### পদ্ধতি ১: Releases থেকে সরাসরি `.apk` ডাউনলোড (সবচেয়ে সহজ)
1. আপনার GitHub রিপোজিটরির ডানপাশে থাকা **Releases** (অথবা `https://github.com/<আপনার-ইউজারনেম>/<রিপো-নাম>/releases`) সেকশনে ক্লিক করুন।
2. **"D. Calc APK (Latest)"** রিলিজের নিচে থাকা **Assets** থেকে **`D-Calc.apk`** ফাইলে ট্যাপ করলেই সরাসরি ফোনে ডাউনলোড হয়ে যাবে।

### পদ্ধতি ২: Actions ট্যাব থেকে ডাউনলোড
1. আপনার GitHub রিপোজিটরির উপরের **Actions** ট্যাবে যান।
2. সর্বশেষ সফল হওয়া **"Build D. Calc APK"** রানটিতে ক্লিক করুন।
3. নিচে **Artifacts** সেকশন থেকে **`D-Calc-APK`** ডাউনলোড করে আনজিপ করলেই `D-Calc.apk` ফাইল পাবেন।

---

### ফোনে ইনস্টল করার নিয়ম:
1. ডাউনলোড করা **`D-Calc.apk`** ফাইলে ট্যাপ করুন।
2. অনুমতি চাইলে *"Allow from this source"* চালু করে **Install** চাপুন।
